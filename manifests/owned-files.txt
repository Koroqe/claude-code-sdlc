# claude-code-sdlc — installer file manifest
#
# Every path is RELATIVE to ~/.claude. Absolute paths, `..` segments, and
# anything outside the allowlisted structure are rejected by install.sh before
# any file is touched. Blank lines and lines whose first character is `#` are
# ignored.
#
# Two sections:
#
#   owns    — the files this version of install.sh places in ~/.claude.
#             These are refreshed on install and removed on --uninstall.
#
#   legacy  — paths installed by EARLIER versions that this version retires.
#             These are removed on upgrade and on --uninstall, and never
#             written. Retired paths must stay listed here permanently:
#             forgetting one leaves a stale file that silently shadows its
#             replacement.
#
# This manifest never lists a file the harness did not install. Removal is
# scoped to these entries only — never a glob — which is what guarantees a
# user's own agents in ~/.claude/agents/ survive every install and uninstall.
